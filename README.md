
> **Wudase Mariam Shuffle Card Game Deliverables
**


User Interface that is easy to use but with appealing shapes and color schemes

Reminders to play the game

Reminders about specific sections of the game and their meaning

Contact form to contact the diocese

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm, included with Node.js
- Expo Go on a physical Android or iOS device, or an Android/iOS emulator

### Install dependencies

From the project directory, run:

```bash
npm install
```

### Start the app

Start the Expo development server with:

```bash
npm start
```

Then scan the QR code with Expo Go, or use one of the platform-specific commands:

```bash
npm run android
npm run ios
npm run web
```

Press `a` or `i` in the Expo terminal to open the app on an Android or iOS emulator. Press `w` to open it in a web browser.
